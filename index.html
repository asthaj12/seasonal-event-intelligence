The Common Thread Across All 4 Stories

Acting before the base forecast has signal requires separating seasonal shape from magnitude, and separating event demand from organic trend. In every story, the base forecast relied on last-year actuals as the primary signal — which fails whenever severity, timing, geography, or event characteristics shift year-over-year. The consistent fix: build a causal model that encodes why demand moves, not just when it moved last year.

BTS: shape/magnitude separation + new-item ramps Cold/Flu: severity + geography + substitution clusters Easter: event-study indexing by weeks-to-holiday Events: item-criticality engine + false-positive elimination
